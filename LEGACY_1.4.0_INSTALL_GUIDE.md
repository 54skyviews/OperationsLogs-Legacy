# OperationsLogs Legacy v1.4.0

This Legacy build contains the same operational Version 1.4 features as the standard app:

- Ready to Launch queued flights
- Take Off Now from the queue
- Full selected-day reconciliation
- Cloud/device flight verification
- Sync Now button
- Master-list refresh on each reconciliation

Use a normal Safari tab, not Private Browsing. Synchronisation is periodic and can
take up to approximately 30 seconds. No Supabase SQL change is required.
